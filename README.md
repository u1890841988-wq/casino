# Lucky Vault — Free Play Casino

A fully client-side virtual casino with five games: Slots, Roulette, Blackjack, Dice, and Plinko.

## File Structure
- `index.html` — Main page markup
- `styles.css` — All styling
- `script.js` — Combined game logic and state management

## How to Run
1. Open `index.html` in any modern browser.
2. No build step, no server, no dependencies required.

## Notes
- All currency is fictional and stored in your browser's localStorage.
- Reset your bankroll anytime using the Reset button in the top bar or on the Stats tab.
